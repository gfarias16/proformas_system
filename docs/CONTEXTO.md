# Contexto do projeto

## Nome e objetivo

Sistema de Proformas mantém proformas, clientes, usuários e solicitações de mudança, consulta câmbio PTAX e exporta relatórios Excel.

## Funcionalidades principais

- Dashboard e listagem/cadastro de proformas.
- Cadastro de clientes e usuários.
- Solicitações de mudança com aprovação ou rejeição.
- Consulta/conversão USD-BRL por PTAX.
- Exportação XLSX.
- Importação legada opcional de planilha.

## Stack

- FastAPI, SQLAlchemy, psycopg2, pandas e openpyxl.
- React/Vite.
- PostgreSQL 17.
- Docker Compose.
